## 1. 功能性缺口

### T1 · 机器人 uid 没落盘

**现状**：`settings.json` 只有 `ownerUid`（主人 110149990088）。机器人自己的 uid 只活在 `/status` 的响应里，没有落盘。

**证据**：`node tools/selfcheck.mjs` 实跑输出 `! 不知道机器人的 uid，跳过「回错到自己」检查`。

**影响**：这是你点名的四个坑之一，现在**无法验证**。她有可能会回自己的评论，账本上看不出来，因为 `authorUid` 和 self 无从比对。

**改法**：`index.js` 里拿到 `/status` 的地方，把 `status.self.user.uid` 写进 `autopilot-state.json`（已有文件，加一个字段）。顺手也给 selfcheck 用。

**验收**：`node tools/selfcheck.mjs` 不再出现 `self-uid-unknown`。

---

### T2 · 没有值班基线

**现状**：自检能说"今天 0 条"，但说不出"今天本该有却没有"。

**证据**：今天 18:00 为止 `budget.json` / `ledger.json` 都停在 11-04 23:0x，而 `picks.json` 17:10 还在更新 —— 刷视频在跑，出口一个没有。

**影响**：值班挂了、额度用光、定时器没起、账号掉登录 —— 这四种故障现在的表现**完全一样**，都是"安静"。你要等到自己想起来去看面板才会发现。

**改法**：在 `selfcheck` 加一条 `duty-silent`：连续 N 小时（默认 6）零出口 **且** 收件箱非空 → error。收件箱为空时只 warn。

**验收**：用真实数据能报出来（今天大概率会报）；把 N 调成 24 就不报。

### T4 · 人设两份，抖音侧是空的

**现状**：`settings.json` 里 `"persona": ""`，`lib/settings.mjs:78` 注释写着"空 = 通用助手口吻"。小汐的人设卡在 `~/.dsh/profiles/desktop/qq-pet/identity.md` + `style.md`，由 cute-hook 每轮注入到 QQ 侧。

**证据**：live settings 实读；`lib/autopilot.mjs:120` 的 `personaLine(s)` 只读 settings。

**影响**：同一个人在两个平台说话不像。这不是模型问题，是喂的东西不一样。

**三个选项**：

| 选项 | 做法 | 优点 | 缺点 |
|---|---|---|---|
| A | 只读 `identity.md` 前 200 字 | 改动最小，一句话定人设 | 没有"怎么说话"，只有"我是谁" |
| B | `identity.md` + `style.md` 的"说话方式"小节 | 口吻能对上 | 注入变长（约 400 字），每次多花 token |
| C | 不读文件，在面板里手写一段 persona | 可控、不会被别人的卡带偏 | 要你自己维护，改人设得改两处 |

**建议 B**，但必须先 `--dry` 跑三条对比口吻再开。

---

### T5 · 点赞 / 收藏没有写操作

**现状**：`lib/api.mjs` 只读 `digg_count` 和通知类型（34/41），没有任何 digg / collect 的 POST。

**影响**：你列的"点赞收藏等互动"目前是 0。而且它属于 `api.mjs` 那个禁改区，动它风险等级和 `budget.mjs` 一样。

**三个选项**：

| 选项 | 做法 | 风险 |
|---|---|---|
| A | 只读确认页：挑卡标"值得赞"，人点一下才真赞 | 低（不新增自动行为） |
| B | 半自动：她看完高分的自动赞，但有小时额度 | 中（需要额度通道 + 退避） |
| C | 暂不做，等号再养一阵 | 无 |

**建议 A**。理由：新号出现"规律点赞"是最容易被判机器行为的特征之一，而你已经有 207 粉丝，不值得拿这个号试。

## 4. 体验债（面板）

### T9 · 看板数字选错了指标

`[data-dys-stat]` 三个数是 粉丝 / 作品 / 获赞，而"待回几条"被塞在胶囊里。
看板的结构是对的（b29 已经做了），**指标选错了**。

**改法**：换成 待回 / 今日额度 / 上一条回评成败；粉丝挪回趋势卡（那边本来就有）。
附带：`[data-dys-stat] b{font-size:15px}` → 20–22px + `tabular-nums`。

### T10 · 无断点、无键盘

- `@media` 只有一条（reduced-motion），720 / 480 断点都没有；分段控件靠 `flex-wrap` 兜底，窄屏会变成三行顶掉内容区
- `keydown = 0`，方案里承诺的 `/` 聚焦搜索、`r` 刷新都没做
